# Skill: Archive Plan Folder

Переносит всё содержимое папки-источника (обычно смены/батча: `night-shift`, `auto`, `sprint-XX`) в `docs/plan/archive/<TIMESTAMP>_<SOURCE_NAME>/`, где `TIMESTAMP` — текущие дата и время в формате `YYYY-MM-DD_HH-MM` (локальное время). Исходная папка остаётся на месте, пустая.

## Параметры запуска

- **SOURCE** — путь к архивируемой папке. По умолчанию `docs/plan/night-shift/`.
  - Если пользователь указал папку в запросе (например «заархивируй `docs/plan/auto/`», «убери night-shift») — взять её.
  - Путь может быть абсолютным или относительным от корня репозитория.
- **ARCHIVE_ROOT** — корень архива. По умолчанию `docs/plan/archive/`.
  - Если пользователь явно указал другую папку назначения — использовать её.
- **TIMESTAMP_FORMAT** — `YYYY-MM-DD_HH-MM` (минуты через дефис, чтобы быть совместимым с shell- и filesystem-friendly именем). Не менять без явной просьбы.

## Алгоритм

### 1. Проверить источник
- Если **SOURCE** не существует или пуст — сообщить пользователю («папка не найдена» / «папка уже пуста») и остановиться. Ничего не создавать и не переносить.

### 2. Зафиксировать имя источника
- `SOURCE_NAME` = basename пути **SOURCE** (например `night-shift`, `auto`, `sprint-42`). Используется в имени целевой папки.

### 3. Получить текущий timestamp
```bash
date '+%Y-%m-%d_%H-%M'
```
Локальное время. Не UTC.

### 4. Сформировать пути
- `DEST_NAME = <TIMESTAMP>_<SOURCE_NAME>` (например `2026-07-18_22-36_night-shift`).
- `DEST_PATH = <ARCHIVE_ROOT>/<DEST_NAME>`.

### 5. Создать целевую папку
```bash
mkdir -p <DEST_PATH>
```

### 6. Перенести содержимое
```bash
mv <SOURCE>/* <DEST_PATH>/
```
- Переносятся файлы и подпапки первого уровня (рекурсивно).
- **Скрытые файлы** (начинающиеся с точки): glob `*` их не ловит. Если в **SOURCE** могут быть скрытые файлы — после основного `mv` проверить остаток и, если есть, перенести отдельно, например:
  ```bash
  find <SOURCE> -mindepth 1 -maxdepth 1 -exec mv {} <DEST_PATH>/ \;
  ```
  (BSD `mv` на macOS не поддерживает `-t`, поэтому через `-exec ... \;`.)
- **Сама папка SOURCE не удаляется** — остаётся пустой для дальнейшего использования. Если пользователь просит удалить и саму папку — после переноса сделать `rmdir <SOURCE>`.

### 7. Проверить результат
- Посчитать количество перенесённых файлов (через `ls <DEST_PATH> | wc -l` или `find <DEST_PATH> -type f | wc -l` для подсчёта с подпапками).
- Убедиться, что **SOURCE** теперь пуста.

## Итог (что сообщить пользователю)

Коротко, в одну-две фразы:
- сколько файлов (и подпапок) перенесено;
- путь назначения `DEST_PATH`.

Пример: «Готово. 28 файлов из `night-shift/` перенесены в `docs/plan/archive/2026-07-18_22-36_night-shift/`.»

## Жёсткие правила

- **Никаких коммитов.** Изменения остаются в working tree; решение о коммите — за человеком.
- **Не угадывать путь.** Если в запросе папка не названа явно — брать `docs/plan/night-shift/` по умолчанию, но в итоговом сообщении явно указать, какую SOURCE использовал, чтобы пользователь заметил ошибку, если имел в виду другое.
- **Идемпотентность по пустоте.** Если SOURCE пуста или отсутствует — ничего не создавать, сообщить и остановиться. Не плодить пустые папки в `archive/`.
- **Имя целевой папки всегда содержит timestamp.** Даже если внутри `archive/` уже есть папка с таким же `SOURCE_NAME` и другой датой — отдельный timestamp гарантирует уникальность и хронологический порядок.
- **Не перезаписывать существующую целевую папку.** Если `DEST_PATH` уже существует (маловероятно при минутном timestamp, но возможно при повторном запуске в ту же минуту) — добавить суффикс `_2`, `_3` и т.д.
- **Кодировка timestamp фиксирована:** `YYYY-MM-DD_HH-MM`. Не использовать другие форматы без явной просьбы.
