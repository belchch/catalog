Управляй TODO-списком проекта.
ПОДКОМАНДА: $1
Полная строка: $ARGUMENTS

## Подготовка
1. FILE = docs/todo/README.md
2. SUB = $1 (первое слово после /todo: `add` | `done`).
3. Если SUB не равен add/done → весь $ARGUMENTS считается текстом новой записи (режим add по умолчанию, для совместимости).
4. Если FILE не существует: в режиме add — создай (см. add); в режиме done — выведи «Список пуст (docs/todo/README.md нет)» и закончи.

## Команды

### add  —  `/todo add <текст>`  (или просто `/todo <текст>`)
1. Если FILE не существует — создай со структурой:
   ```
   # TODO

   - [ ] <ТЕКСТ>
   ```
2. Если FILE существует — прочитай, найди блок списка (строки `- [ ] ...` или `- [x] ...`).
   - Добавь `- [ ] <ТЕКСТ>` сразу после ПОСЛЕДНЕГО пункта списка (сохрани те же отступы/формат, что у соседних).
   - Если списка ещё нет — вставь пустую строку после заголовка `# TODO` и добавь `- [ ] <ТЕКСТ>`.
   - Сохрани все остальные строки, заголовки и порядок без изменений.
3. Запиши файл. Сообщи: «Добавлено в docs/todo/README.md: <ТЕКСТ>».

### done  —  `/todo done <№>`  или  `/todo done <текст>`
1. Прочитай FILE. Собери в порядке следования все НЕВЫПОЛНЕННЫЕ пункты `- [ ] ...` (1-индексация по счётчику).
2. Цель выбора:
   - Если аргумент — целое число № → N-й по счёту невыполненный пункт.
   - Иначе — текст → первый `- [ ] ...`, в котором встречается подстрока (без учёта регистра).
3. Замени у найденного пункта `- [ ]` → `- [x]` (сам текст пункта не меняй).
4. Если цель не найдена → сообщи «Не найдено невыполненного пункта по: <аргумент>» и закончи.
5. Запиши файл. Сообщи: «Выполнено: <текст пункта>».

## Жёсткие правила
- За один запуск — ровно ОДНО действие (add одной записи или done одного пункта).
- Не переупорядочивай, не удаляй и не редактируй текст существующих пунктов.
- Соблюдай отступы/форматирование соседних пунктов.
- Не коммить изменения — решение за человеком.
