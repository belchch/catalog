# ADR 0008: FTS — системный скилл, после первого среза

- **Date:** 2026-07-12
- **Status:** Accepted

## Context
fable G1: поиска по содержимому не было. Заказчик хочет FTS не как UI-поле, а как возможность, о которой **модель знает и вызывает сама** (code-командами).

## Decision
FTS (SQLite FTS5 над текстом документов) реализован как **системный скилл/инструмент** `search_documents(query)`, который агент вызывает через function-calling. Это первый системный скилл; добавляется **сразу после первого среза** (осмыслен только при нескольких документах).

## Consequences
**Плюсы:** соответствует концепции системных скиллов; переиспользуется любым скиллом; поиском управляет модель.
**Минусы:** не входит в первый срез (намеренно отложен).

## Alternatives considered
- UI-поле поиска по названию/контенту — отклонено: не вызывается моделью.
- Эмбеддинги/семантический поиск — отложено: тяжелее.
