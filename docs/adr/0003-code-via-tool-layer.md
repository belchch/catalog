# ADR 0003: Code-возможность — базовая, через слой инструментов

- **Date:** 2026-07-12
- **Status:** Accepted
- **Revised by:** ADR-0014 (детерминированный код как отдельный тип скилла), ADR-0016 (инструменты видят только документы сессии)

## Context
fable предложил(а) трактовать python/кодогенерацию как бонусную («если успеем»). Заказчик это отверг: **код — базовая фича скилла**, а не опциональная.

## Decision
Code — это не опциональный «тип шага», а **слой инструментов**, который вызывает любой скилл: `list_documents`, `read_document`, позже `search_documents` и др. Инструменты — обычные функции в коде, вызываемые агентом через function-calling. Каждое исполнение скилла может их использовать; они никогда не «бонус».

## Consequences
**Плюсы:** выполняет требование «python — базовая фича»; единообразная расширяемость (добавил инструмент → все скиллы его получили).
**Минусы:** произвольная кодогенерация пользовательских `.py` отложена; первый срез поставляется с фиксированным реестром инструментов, sandbox планируется на момент открытия авторизации инструментов.

## Alternatives considered
- Опциональный тип шага `code` — отклонено: провоцирует «выкидывание» кода при нехватке времени.
- Произвольная LLM-кодогенерация в v1 — отклонено: хрупко без sandbox.
