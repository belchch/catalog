# ADR 0002: Скилл = замороженный конфиг агента

- **Date:** 2026-07-12
- **Status:** Accepted (текст ниже уточнён более поздними ADR — см. «Актуальное состояние»)
- **Revised by:** ADR-0014 (`kind="script"` снимает запрет на `.py`), ADR-0015 (build = упаковка артефактов), ADR-0017 (параметры применения), ADR-0018 (заморозка наступает на commit)

## Context
Понятие скилла «гуляло» между двумя крайностями: «сгенерированная python-функция» (opus) и «дистиллированная финальная сессия» (fable G4). Обе смешивают скилл либо с кодогенерацией, либо с извлечением из хаотичного чата постфактум.

## Decision
Скилл = **замороженный конфиг агента**:
```
{ name, description, system_prompt, allowed_tools[], model, temperature=0,
  max_iterations, max_retries, verify_checks[], output_kind }
```
«Применить скилл» = запустить агент-луп с этим конфигом над документом. Никакой сгенерированной под скилл `.py`; никакой дистилляции сессии.

## Consequences
**Плюсы:** просто, единообразно, инспектируемо; тривиально хранится (SQLite); переиспользуется повторным запуском.
**Минусы:** скилл не лучше своего `system_prompt` + набора инструментов; выразительность ограничена реестром инструментов (расширяется со временем).

## Alternatives considered
- Генерация `.py` под каждый скилл — отклонено: риски исполнения (безопасность) и недетерминизм кодогенерации.
- Дистилляция из лога сессии — отклонено: сложно и хрупко (fable G4).

## Актуальное состояние (2026-07-24, сверено с кодом)

Ядро решения в силе: скилл — это данные (конфиг), а не код приложения, и
«применить» = запустить движок с этим конфигом. Изменились три вещи.

**1. Состав конфига вырос** (`backend/app/skills/config.py`):
```
{ name, description, system_prompt, allowed_tools[], model, temperature=0,
  max_iterations, max_retries, verify_checks[], output_kind,
  kind, code, non_determinism_reason,      # ADR-0014
  input_arity,                             # ADR-0017
  provider, reasoning }                    # CATALOG-6
```

**2. «Никакой сгенерированной `.py`» действует только для `kind="agent"`.**
Для `kind="script"` код — часть конфига (поле `code`), исполняется
sandbox-раннером без LLM в рантайме (ADR-0014). Дистилляция сессии
по-прежнему не делается: build упаковывает артефакты, материализованные
планировщиком по ходу диалога (ADR-0015).

**3. «Заморожен» — с момента commit, не с момента build.** Черновик
(`status="draft"`) настраивается через `PATCH /skills/{id}/configure`;
закоммиченный скилл меняется только через edit-сессию, которая возвращает
его в `draft` (ADR-0018). Применение параметризуется вне конфига —
`input_arity`, runtime-prompt и режим вывода живут в запросе и строке
прогона (ADR-0017).
