# ADR 0019: Пользовательский скилл как вызываемый тул сессии

- **Date:** 2026-08-16
- **Status:** Accepted
- **Extends:** ADR-0002, ADR-0008, ADR-0014, ADR-0015
- **Clarifies:** ADR-0018 (альтернатива `run_script` как тул)

## Context

Базовый реестр инструментов агента содержит только `list_documents` и
`read_document`. Пользовательские скиллы — замороженные операции над
документами — не доступны планировщику и agent-скиллу как callable tools.

ADR-0018 отклонил «`run_script` как тул», потому что в той формулировке
`code` генерирует модель на каждом вызове (code interpreter). Это другая
задача: здесь код уже заморожен в `config_json` скилла.

## Decision

1. К сессии прикрепляются скиллы (`session_skill`), по аналогии с
   `session_document`. Прикрепление = разрешение модели вызвать скилл.
2. Каждый прикреплённый скилл регистрируется как tool в WS-сессии.
   Первый срез: только `kind="script"`, глубина вложенности 1.
3. Вызов создаёт отдельный `skill_run` с `parent_run_id` и прогоняет
   `verify_checks` вызванного скилла. В трейс пишутся id и хэш
   `config_json` (пиннинг на момент вызова).
4. Вход тула — текст (`text` или `texts`), не обязательно документ.
   `_apply_core` принимает `input_texts` без загрузки документов.
5. Имя тула — slug с префиксом `skill_`, без коллизий с системными.

## Consequences

**Плюсы:** композиция без code interpreter; verify как постусловие;
дерево запусков через `parent_run_id`.

**Минусы / риски:** рост стоимости при расширении на agent/pipeline;
нужен поиск в UI при большом числе скиллов.

## Alternatives considered

- **Читать скилл как инструкцию в чате** — отклонено: модель может
  отклониться от сценария; нет отдельного run и verify.
- **Все committed скиллы workspace всегда в реестре** — отклонено:
  нет явного разрешения пользователя; перегрузка контекста.
- **Code interpreter (`run_script` с code от модели)** — остаётся
  отклонённым для воспроизводимых скиллов (ADR-0018); не путать с
  вызовом замороженного script-скилла.

## Relation to ADR-0018

Формулировка «`run_script` как тул отклонено» относится к генерации
кода моделью в рантайме. Вызов замороженного `kind=script` скилла как
тула — этот ADR; ADR-0018 остаётся в силе для sandbox и pipeline.
