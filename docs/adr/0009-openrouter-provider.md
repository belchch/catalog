# ADR 0009: LLM через OpenRouter (selector + pin + streaming)

- **Date:** 2026-07-12
- **Status:** Accepted

## Context
Нужны облачные модели сейчас (дом/Mac), путь к локальным моделям позже (корп/офлайн) и выбор модели под роль/шаг. opus: абстрагировать `LLMProvider` с первого дня. Заказчик: провайдер = **OpenRouter**, модель выбирается из списка; разные шаги/роли могут использовать разные модели.

## Decision
Тонкий `LLMProvider`; первая реализация — `OpenRouterProvider` (`complete` + `list_models` + **pin провайдера** + streaming). `temperature=0` по умолчанию для воспроизводимости. Pin провайдера хранится в конфиге скилла, чтобы снизить вариативность между бэкендами OpenRouter.

## Consequences
**Плюсы:** единая точка интеграции; лёгкий переход на Ollama/корп-gateway позже; per-role модели.
**Минусы:** маршрутизация OpenRouter может влиять на воспроизводимость (сглаживается pin провайдера + `temp=0`).

## Alternatives considered
- Прямые SDK Anthropic/OpenAI — отклонено: lock-in, тяжелее миграция в корп.
- Только локальные модели сейчас — отклонено: качество.
