# CATALOG-104 — Дизайн UI

- **Источник:** `docs/plan/2-shift/05-CATALOG-104-ui-sidebar-footer-workspace.md`
- **Статус дизайна:** Ready

## Цель и пользовательский путь

Сайдбар сейчас повторяет сам себя: слово «Catalog» звучит и в верхнем header, и в brand-строке сайдбара; имя папки — и в `WorkspaceBar` под меткой «Проект», и в футере (`display_name || path`). Плюс скроллится весь `aside` целиком, поэтому футер уезжает вместе с контентом и перестаёт быть якорем.

Целевая картина — три яруса сайдбара с одним смыслом на ярус:

1. **Шапка (фиксирована):** поиск + «Новый чат». Никакого бренда — он уже есть в верхнем header приложения.
2. **Секции (скроллятся):** Сессии / Документы / Скиллы. Скролл живёт только здесь.
3. **Футер (закреплён):** единственное место, где показано имя воркспейса, и единственная точка входа в смену папки и рескан.

Сценарий:

1. Пользователь открывает приложение. В сайдбаре сверху — поиск и «Новый чат», внизу закреплена плашка с именем текущей папки; посередине скроллятся секции.
2. Пользователь листает длинный список сессий — плашка футера остаётся на месте, шапка тоже.
3. Пользователь наводит на плашку: строка подсвечивается во всю ширину сайдбара, `⌄` становится контрастнее — читается как «здесь можно переключиться». Клик открывает пикер воркспейса.
4. Пользователь нажимает иконку рескана справа в плашке: иконка сменяется спиннером, кнопка становится `disabled`, `aria-busy="true"`; по завершении возвращается `RefreshIcon`.
5. Если папка не открыта — плашка показывает «Папка не открыта» приглушённым текстом, остаётся кликабельной (открывает пикер), иконки рескана нет. Отдельная кнопка «Открыть папку» в сайдбаре не нужна: крупный CTA уже есть в пустом состоянии `main` (`App.tsx`, блок «Воркспейс не открыт»).

Вне scope: содержимое пикера, поведение поиска (по-прежнему декоративная плашка), иерархия/типографика заголовков секций (CATALOG-105), sticky-заголовки (CATALOG-106).

## Layout и состояния

### Каркас сайдбара

```
<aside class="catalog-sidebar flex min-h-0 flex-col overflow-hidden p-3">
  ├── .catalog-search        (flex: none)
  ├── .catalog-new-chat      (flex: none)
  ├── .catalog-sidebar__sections   (flex: 1; min-height: 0; overflow-y: auto)  ← 3× CollapsibleSection
  └── <WorkspaceFooter/> → .catalog-sidebar__footer (flex: none)
</aside>
```

Правила CSS (`index.css`):

- `.catalog-search`, `.catalog-new-chat` — добавить `flex: none`. Без этого при переполнении flex-контейнера шапка сожмётся: у поиска фиксированная `height: 34px`, и он схлопнется первым.
- `.catalog-sidebar__sections` — к текущим `display:flex; flex-direction:column; gap:2px` добавить `flex: 1; min-height: 0; overflow-y: auto; overscroll-behavior: contain`. `overscroll-behavior` не даёт скроллу «протечь» в `main`.
- `.catalog-sidebar__footer` — `margin: auto -12px -12px` → `margin: 0 -12px -12px`; добавить `flex: none`. Отрицательные горизонтальные margin остаются: именно они дают full-bleed кромку и линию во всю ширину сайдбара.

Прижимает футер вниз теперь не `margin-top:auto`, а `flex:1` у секций — при коротком контенте секции просто занимают всё свободное место, футер стоит на дне.

### Плашка футера

Внутри `.catalog-sidebar__footer` — строка из двух **сестринских** (не вложенных) контролов:

```
[ ▱  Имя папки ……………………………  ⌄ ]  [ ⟳ ]
   picker button (flex-1, min-w-0)      rescan
```

- Контейнер футера: `display:flex; align-items:center;`, **без горизонтального padding** — паддинг несёт сама кнопка-пикер, иначе hover не дотянется до кромок. Правый край: `padding-right: 8px` (чтобы icon-кнопка не липла к границе сайдбара). `border-top: 1px solid var(--sidebar-line)` — сохранить.
- Кнопка-пикер: `flex: 1; min-width: 0`, `padding: 11px 12px 11px 20px` (вертикаль в коридоре ТЗ 10–12px, левый отступ 20px компенсирует bleed −12px и визуально совпадает с отступами секций), `border-radius: 0`, `text-align: left`.
- Icon-кнопка рескана: 32×32 (`size-8`), `rounded-control`, `shrink-0`.

Состояния:

| Состояние | Условие | Что показываем |
|---|---|---|
| Есть воркспейс | `path` не пустой | `▱` + `folderLabel` (`--ink`, 600, `truncate`) + `⌄`; справа кнопка рескана; `title` = полный `path` |
| Идёт рескан | `rescanning === true` | То же, но в кнопке рескана `SpinnerIcon`, кнопка `disabled` + `aria-busy="true"`; плашка-пикер остаётся активной |
| Нет воркспейса | `path === null` | `▱` + «Папка не открыта» (`--ink-faint`, вес 400) + `⌄`; кнопки рескана нет; `title` отсутствует |

Ошибок и загрузки у самой плашки нет: результат рескана показывает `RescanReportModal`, ошибки воркспейса — `catalog-notice` в шапке приложения. Плашка не мигает при обновлении списков секций.

### `<lg` (ширина < 1024px)

Сайдбар скрыт (`@media (max-width: 1023px) { .catalog-sidebar { display: none } }`, `index.css:380-381`), раскладка — одна колонка `main`. Значит риск «футер/секции схлопнутся в `grid-cols-1`» снимается сам собой; проверять надо ровно одно: после смены `overflow` на `aside` при <1024px не появляется вторая полоса прокрутки и `main` по-прежнему занимает всю высоту. Сценарий «нет воркспейса» на узком экране закрыт кнопкой «Открыть папку» в пустом состоянии `main` — поэтому одноимённую кнопку из `WorkspaceBar` не переносим.

## Взаимодействия

- **Клик по плашке** (в любой её точке: глиф, текст, `⌄`) → `onOpenPicker()`. Обработчик — один, на кнопке; `⌄` и `▱` — `aria-hidden`, отдельных обработчиков не имеют.
- **Клик по иконке рескана** → `onRescan()`. Кнопка физически вне кнопки-пикера (вложенные `<button>` недопустимы), клик по ней не открывает пикер.
- **Hover плашки:** фон `var(--sidebar-brand-hover)` во всю ширину плашки, включая левую кромку сайдбара (full-bleed, без скруглений и без внутренних зазоров). `⌄` синхронно уходит с `--ink-faint` на `--ink-muted`. Переход — `transition-colors`, как у `.catalog-new-chat`.
- **Hover иконки рескана:** свой фон `var(--sidebar-brand-hover)` со скруглением `--radius-control`; фон плашки при этом не подсвечивается.
- **Клавиатура:** Tab даёт два стопа в порядке «плашка → рескан»; Enter/Space срабатывают штатно (обычные `<button type="button">`).
- **Рескан в процессе:** повторное нажатие невозможно (`disabled`), ширина кнопки не прыгает — `SpinnerIcon` и `RefreshIcon` одного размера (18px).
- **Длинное имя папки:** `truncate` в один ряд; полный путь доступен в `title`. Плашка никогда не переносится на вторую строку и не меняет высоту.
- **Скролл секций:** колесо/тачпад над секциями скроллит только их; шапка и футер неподвижны. Внутренние скроллы списков (`SessionsPanel`, `DocumentList`, `SkillsPanel`) не меняются.

## Стиль и токены

Только существующие переменные из `:root`, новых токенов не вводим.

- Плашка (текст): 14px, `font-weight: 600`, `color: var(--ink)`. Это громче списков секций (14px/400–500) — шкала «футер > списки > заголовки», нужная CATALOG-105.
- Пустое состояние: `color: var(--ink-faint)`, `font-weight: 400` (утилиты `text-ink-faint font-normal`, как было в `WorkspaceBar`).
- Глиф `▱`: 18px, `line-height: 1`, `color: var(--ink-faint)`, `shrink-0`. Тот же символ, что в верхнем header (`.catalog-header__folder`) и в пустом состоянии `main` — папка везде обозначается одинаково. Кружок-аватар `C` уходит.
- `⌄`: 16px, `color: var(--ink-faint)`, `margin-left: auto`, `shrink-0`, `aria-hidden`. Без вращения — состояния «раскрыто» у пикера нет, шеврон означает «откроется выбор».
- Gap внутри плашки: 10px (`gap-2.5`) между глифом и текстом.
- Иконки рескана: `size-[18px]`, цвет наследуется от плашки (`--ink`), как решено в CATALOG-101. `disabled:opacity-50 disabled:cursor-not-allowed`.
- Разделитель футера: `border-top: 1px solid var(--sidebar-line)` — без изменений.

Мёртвый CSS удалить: `.catalog-sidebar__brand`, `.catalog-sidebar__chevron`, `.catalog-project-title`, `.catalog-avatar` (включая её участие в общем правиле `.catalog-mark, .catalog-avatar`), а также `.catalog-sidebar__section-label` — после удаления метки «Проект» у него не остаётся ни одного потребителя, и планы 105/106 на него не ссылаются. `.catalog-mark` и `--mark-bg` **не трогать**: `.catalog-mark` используется в `SetupKeyScreen.tsx:72`.

## Доступность (a11y)

- Плашка: `<button type="button">` с `aria-haspopup="dialog"` и `aria-label={label}` (метка = видимый текст, включая «Папка не открыта»). `title={path ?? undefined}` — только подсказка, не замена метки.
- Рескан: `<button type="button">` с `aria-label="Пересканировать"`, `title="Пересканировать"`, `aria-busy={rescanning}`, `disabled={rescanning}`.
- Декоративные `▱` и `⌄` — `aria-hidden="true"`, чтобы скринридер читал только имя папки.
- Фокус: `focus-visible:ring-2 focus-visible:ring-brand`. Для плашки ring обязательно **inset** (`focus-visible:ring-inset`): она full-bleed и выходит за кромку `aside`, у которого теперь `overflow-hidden`, — внешнее кольцо подрезалось бы. У кнопки рескана кольцо обычное (она внутри паддинга).
- Контраст: `--ink` на `--sidebar` и `--ink-faint` на `--sidebar-brand-hover` — уровни, уже используемые в сайдбаре; новых сочетаний не вводим.
- Скроллящийся контейнер секций фокусируется браузером штатно; `tabindex` не навешиваем — внутри есть фокусируемые контролы.
- `SpinnerIcon` уже уважает `motion-reduce` — оставить как есть.

## Контракты данных

Новых API и WS-контрактов нет. Данные — те же, что использовал `WorkspaceBar`:

- `workspace.current?.path`, `workspace.current?.display_name` из `useWorkspace` (`App.tsx:110`).
- `rescanning` (`App.tsx:141`), `handleRescan` (`:239`), `openPicker` (`:212`).

`folderLabel` сохраняет прежнее поведение: `null` → «Папка не открыта»; непустой `display_name` → он; иначе — последний сегмент пути (с отрезанными хвостовыми `/`), при пустом сегменте — сам путь.

## Критерии визуальной приёмки

- [ ] Слово «Catalog» встречается в UI один раз — в верхнем header; brand-строки в сайдбаре нет.
- [ ] Имя папки в сайдбаре одно — в футере; текст равен `folderLabel` (не полный путь), полный путь только в `title`.
- [ ] Метки «Проект» в сайдбаре нет; `WorkspaceBar` в дереве не рендерится, файл удалён.
- [ ] При скролле длинного списка сессий шапка (поиск + «Новый чат») и футер остаются на месте; двигаются только секции.
- [ ] Полоса прокрутки принадлежит блоку секций, а не `aside`; у `aside` `overflow-hidden`, у секций `flex:1; min-height:0; overflow-y:auto`.
- [ ] При коротком контенте футер прижат к низу сайдбара (без `margin-top:auto`), линия `border-top` идёт во всю ширину сайдбара.
- [ ] Hover плашки закрашивает строку до левой кромки сайдбара, без скруглений и внутренних зазоров; `⌄` при этом темнеет.
- [ ] Клик по любому месту плашки открывает пикер; клик по иконке рескана пикер не открывает.
- [ ] Кнопка рескана — сестра плашки, а не вложенная в неё (в DOM нет `<button>` внутри `<button>`).
- [ ] Во время рескана: `SpinnerIcon`, `disabled`, `aria-busy="true"`, ширина кнопки не меняется.
- [ ] Без воркспейса: «Папка не открыта» приглушённым текстом нормального веса, плашка кликабельна, кнопки рескана нет, кнопки «Открыть папку» в сайдбаре нет.
- [ ] Глиф в футере — `▱` (кружка `C` нет); имя папки — `--ink`, вес 600, вертикальный паддинг строки 10–12px.
- [ ] Tab по сайдбару даёт фокус-кольцо, видимое целиком (у плашки — inset, не подрезано кромкой `aside`).
- [ ] Очень длинное имя папки обрезается многоточием в одну строку, высота футера не меняется.
- [ ] В `index.css` нет `.catalog-sidebar__brand`, `.catalog-sidebar__chevron`, `.catalog-project-title`, `.catalog-avatar`, `.catalog-sidebar__section-label`; `.catalog-mark` и `--mark-bg` на месте.
- [ ] При ширине < 1024px сайдбар скрыт, второй полосы прокрутки нет, пустое состояние `main` со своей кнопкой «Открыть папку» работает как раньше.
