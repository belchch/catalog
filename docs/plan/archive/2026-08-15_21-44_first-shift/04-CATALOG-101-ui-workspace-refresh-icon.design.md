# CATALOG-101 — Дизайн UI

- **Источник:** `docs/plan/first-shift/04-CATALOG-101-ui-workspace-refresh-icon.md`
- **Статус дизайна:** Ready

## Цель и пользовательский путь
Строка воркспейса в сайдбаре (`WorkspaceBar`) содержит два действия: слева — открыть/сменить папку, справа — пересканировать. Правое действие сейчас нарисовано Unicode-глифом `⟳` размером ~14px: оно теряется на фоне названия (15px/600) и не читается как кнопка.

Сценарий:
1. Пользователь видит строку с открытой папкой: `▱ Имя папки` и справа — заметную иконку обновления (18px).
2. Наводит курсор — под иконкой появляется квадратная подложка hover, подтверждающая кликабельность.
3. Кликает — начинается пересканирование: иконка сменяется спиннером **того же размера и в том же боксе**, кнопка блокируется. Ни ширина кнопки, ни высота строки не меняются.
4. Скан завершён — возвращается иконка обновления, кнопка снова активна.

Скоуп строго ограничен правой кнопкой: левая кнопка (название + `▱`), высота строки и раскладка не меняются.

## Дерево компонентов и файлы
- `frontend/src/components/WorkspaceBar.tsx` — **изменяется**. Только JSX и классы правой кнопки rescan (сейчас строки 45–56): бокс кнопки и её содержимое.
- `frontend/src/components/icons.tsx` — **не изменяется**. `RefreshIcon` и `SpinnerIcon` уже принимают `className`; размер задаётся утилитой Tailwind, проп размера не нужен (CSS перебивает presentational-атрибуты `width`/`height` в SVG).
- Новых компонентов и зависимостей нет.

## Layout и состояния
Контейнер строки `.catalog-project-title !mb-0 flex items-center gap-1 !p-0` и левая кнопка — **без изменений**.

Правая кнопка перестаёт быть «текстовой» и становится квадратным icon-боксом фиксированного размера:

- **Бокс кнопки:** `shrink-0 inline-flex size-8 items-center justify-center rounded` + текущие `hover:bg-[var(--sidebar-brand-hover)] focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-brand disabled:cursor-not-allowed disabled:opacity-50`.
  - Классы `px-2 py-1.5 text-sm` удаляются: размер задаёт `size-8`, а `text-sm` больше ни на что не влияет (внутри только SVG).
  - `size-8` = 32px — ровно текущая вычисленная высота кнопки (`py-1.5` 6px + line-height `text-sm` 20px + 6px), поэтому высота строки гарантированно не меняется. Ширина растёт на ~2px (с ~30px до 32px) — это допустимо, кнопка `shrink-0`, лишние пиксели забирает `truncate` у названия.
  - `inline-flex items-center justify-center` обязателен: он убирает baseline-зазор под inline-SVG и центрирует глиф в боксе.
- **Иконка внутри:** 18px через `size-[18px]` (Tailwind 3.4 поддерживает `size-*`, в проекте уже используются `size-7`, `size-9`, `size-3.5`).

Состояния кнопки:

| Состояние | Содержимое | Оформление |
|---|---|---|
| idle | `<RefreshIcon className="size-[18px]" />` | цвет наследуется от строки (`currentColor`), фон прозрачный |
| hover | то же | подложка `var(--sidebar-brand-hover)`, скруглённый квадрат 32×32 |
| focus-visible | то же | `ring-2 ring-brand` по тому же квадрату |
| rescanning (`disabled`) | `<SpinnerIcon className="size-[18px]" />` | `opacity-50`, `cursor-not-allowed`, hover-подложка не появляется |

Состояния «empty» (папка не открыта) и «error» у этой кнопки нет: при `!hasWorkspace` кнопка не рендерится вовсе, а ошибки скана показывает `WorkspacePicker` — это поведение сохраняется без изменений.

## Взаимодействия
- Клик по кнопке → `onRescan()`. Во время `rescanning` кнопка `disabled`, повторный клик невозможен — как сейчас.
- Смена idle → rescanning не должна вызывать layout shift: оба состояния — SVG 18×18 в боксе 32×32, поэтому геометрия идентична по построению. Это ключевое требование задачи, и оно решается одинаковым боксом, а не подгонкой ширины текста.
- Спиннер крутится (`animate-spin`), при `prefers-reduced-motion` анимация выключается — это уже зашито в `SpinnerIcon`.
- Крайние случаи:
  - Очень длинное имя папки — левая кнопка `min-w-0 flex-1` + `truncate` продолжает сжиматься, кнопка rescan не сжимается (`shrink-0`).
  - Быстрые повторные клики — блокируются `disabled`.
  - Иконка не должна перехватывать клик отдельно от кнопки: SVG внутри кнопки, `pointer-events` не переопределяем.

## Стиль и токены
- Размер иконки: `size-[18px]` — верх диапазона 17–18px из ТЗ; при `strokeWidth: 1.75` в `iconBase` линии остаются чёткими.
- Цвет: **не задавать** явный класс цвета. Иконка наследует цвет строки воркспейса (`.catalog-project-title` → `--ink`), как сейчас наследует `⟳`. Приглушать до `text-ink-faint` (как в `btn-icon-ghost`) нельзя — задача требует сделать элемент заметнее, а не тише.
- Hover-токен остаётся `var(--sidebar-brand-hover)` — консистентно с левой кнопкой и `.catalog-new-chat`; не переходить на `hover:bg-surface-hover` из `btn-icon-ghost`, иначе кнопка выпадет из палитры сайдбара.
- Скругление `rounded` — как у соседней кнопки; `rounded-full` не использовать.
- Готовый класс `btn-icon-ghost` **не применять**: он тянет `text-ink-faint`, `hover:bg-surface-hover` и `size-7` (28px) — все три пункта конфликтуют с контекстом сайдбара и с целью «крупнее».

## Доступность (a11y)
- `aria-label="Пересканировать"` и `aria-busy={rescanning}` сохраняются на кнопке без изменений.
- Иконки уже `aria-hidden` + `focusable={false}` через `iconBase`, поэтому доступное имя кнопки — только `aria-label`; текстового содержимого у кнопки не остаётся, и это корректно.
- Фокус: `focus-visible:ring-2 ring-brand` сохраняется; после увеличения бокса кольцо описывает квадрат 32×32 — видимость фокуса не ухудшается.
- Клавиатура: кнопка остаётся нативным `<button type="button">`, Enter/Space работают, в `disabled` из таб-порядка выпадает — поведение прежнее.
- Хит-таргет вырастает с ~30×32 до 32×32 — небольшое улучшение, регрессий нет.
- Контраст: цвет наследуется от строки, поэтому не хуже текущего.

## Контракты данных (если нужны)
Не требуются. Пропсы `WorkspaceBarProps` (`rescanning`, `onRescan`, …) не меняются, API и WS не затрагиваются.

## Критерии визуальной приёмки
- [ ] В строке воркспейса справа отрисован `RefreshIcon` (SVG), а не Unicode `⟳`; его размер 18×18 CSS-пикселей.
- [ ] Иконка визуально центрирована в кнопке по вертикали и горизонтали, без baseline-сдвига вниз.
- [ ] Кнопка rescan — квадрат 32×32 (`size-8`), классы `px-2 py-1.5 text-sm` на ней отсутствуют.
- [ ] Высота строки воркспейса до и после изменения одинакова (32px по кнопке); левая кнопка, `▱` и `truncate` у названия не тронуты.
- [ ] При `rescanning` в кнопке `SpinnerIcon` того же размера `size-[18px]`; бокс кнопки не меняет ни ширину, ни высоту при переключении idle ↔ rescanning.
- [ ] Hover даёт подложку `var(--sidebar-brand-hover)` по всему квадрату кнопки; в состоянии `rescanning` кнопка приглушена и не реагирует на hover.
- [ ] Фокус-кольцо `ring-2 ring-brand` видно при навигации с клавиатуры.
- [ ] `aria-label="Пересканировать"` и `aria-busy` присутствуют на кнопке; SVG не попадает в доступное имя.
- [ ] `frontend/src/components/icons.tsx` не изменён.
