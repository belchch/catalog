- **Тип шага:** ui

- **Цель:** Иконка пересканирования в строке workspace заметно крупнее (~17–18px) и читается как кнопка; при `rescanning` кнопка не дёргается; высота строки, название и `▱` не меняются.

## Постановка задачи (актуальное ТЗ)
_(источник: описание задачи — комментариев не было)_

`⟳` справа от названия workspace слишком мелкая. В `WorkspaceBar.tsx` (кнопка 46–55) поднять размер с `text-sm` (~14px) до ~17–18px. Синхронно увеличить `…` при `rescanning`, чтобы ширина кнопки не прыгала. Высоту строки сохранить (`px-2 py-1.5` можно чуть поджать). Не трогать название и `▱`. Опционально заменить Unicode на `<RefreshIcon />` из `icons.tsx`, как в `MessageCommands.tsx`.

## Контекст
Кнопка сейчас:

```46:55:frontend/src/components/WorkspaceBar.tsx
          <button
            type="button"
            className="shrink-0 rounded px-2 py-1.5 text-sm hover:bg-[var(--sidebar-brand-hover)] ..."
            ...
          >
            {rescanning ? '…' : '⟳'}
          </button>
```

`text-sm` на всей кнопке задаёт ~14px и для иконки, и для `…`. Строка — `catalog-project-title` + `flex items-center` (`:28`); название и `▱` живут в соседней кнопке (`:29-44`) — их классы не трогать.

`RefreshIcon` (`icons.tsx:18-26`) по умолчанию 16×16. Для 17–18px — `className` с явным размером. В `MessageCommands.tsx:87` иконка без override (16px) — это другой контекст, копировать размер оттуда не обязательно.

## Затрагиваемые файлы
- `frontend/src/components/WorkspaceBar.tsx` — размер глифа / `RefreshIcon` и слот `…`; при необходимости padding кнопки, не высота всей строки.
- `frontend/src/components/icons.tsx` — только если понадобится проп размера; скорее достаточно `className`.

## План действий
1. Увеличить глиф до ~17–18px: `text-lg` / `text-[17px]` на span внутри кнопки **или** `<RefreshIcon className="h-[18px] w-[18px]" />`. Предпочтительнее SVG — стабильнее baseline, чем Unicode `⟳`.
2. Слот загрузки той же ширины/высоты, что иконка (`inline-flex w-[18px] justify-center` или тот же класс размера на `…`), чтобы кнопка не скакала.
3. Если увеличенный глиф раздувает строку — ужать `py-1.5` у кнопки rescan, не у кнопки названия.
4. Не менять классы `▱` и `truncate` у label.
5. Проверить визуально: idle, hover, `rescanning`, фокус-кольцо; высота строки до/после одинаковая.

## Критерии приёмки (Definition of Done)

- [ ] При пересканировании кнопка не меняет размер.
- [ ] Высота строки workspace, название и левая `▱` не изменились.
- [ ] `aria-label="Пересканировать"` и `aria-busy` на месте.
