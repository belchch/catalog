## Контекст

Боковое меню рендерится в `frontend/src/App.tsx:232-251` — это `<aside>` с тремя панелями:

1. `SessionsPanel` (`frontend/src/components/SessionsPanel.tsx`) — список сессий + кнопки «Новый чат»/«Обновить»
2. `DocumentList` (`frontend/src/components/DocumentList.tsx`) — список документов + загрузка
3. `SkillsPanel` (`frontend/src/components/SkillsPanel.tsx`) — список скиллов с действиями

Сейчас все три разделы рендерятся открытыми, один под другим, без возможности свернуть. Состояние сворачивания — только локальное (client-side), не нужно сохранять в backend.

## Затрагиваемые файлы

- `frontend/src/App.tsx` — обернуть каждую из трёх панелей в `<details>` или кастомный компонент-коллапсер с `defaultOpen={false}` (или `open` state)
- `frontend/src/components/SessionsPanel.tsx` — возможна адаптация заголовка (если нужно вынести его наружу коллапсера)
- `frontend/src/components/DocumentList.tsx` — аналогично
- `frontend/src/components/SkillsPanel.tsx` — аналогично

## План действий

1. Создать общий компонент-обёртку `CollapsibleSection` (в `frontend/src/components/CollapsibleSection.tsx`) — принимает `title` (string), `open` (boolean), `onToggle` (callback), `children`. Рендерит заголовок с chevron-иконкой (▶/▼) и тело, скрытое/показанное через `open`. Либо использовать нативный `<details>` + `<summary>` с кастомными стилями.
2. В `App.tsx` добавить три `useState<boolean>(false)` для каждого раздела (или один `Record<string, boolean>`).
3. Обернуть `<SessionsPanel>`, `<DocumentList>`, `<SkillsPanel>` в `CollapsibleSection` с заголовками «Сессии», «Документы», «Скиллы» соответственно. Все три — свёрнуты по умолчанию (`false`).
4. Убрать дублирующиеся заголовки `<h2>` внутри самих панелей (SessionsPanel, DocumentList, SkillsPanel), т.к. заголовок теперь у коллапсера.
5. Стилировать коллапсер в духе существующего дизайна (slate-900/slate-800, rounded, text-sm font-semibold).
