# CATALOG-10 — Панель команд под сообщением пользователя в чате

- **Задача Plane:** [CATALOG-10](https://app.plane.so/belchch/projects/catalog-app/work-items/10) (id: `28754625-2595-41c1-9c93-1b551caa8c22`, state: In Progress)
- **Статус плана:** Analyzed
- **Тип шага:** ui
- **Предпосылки:** нет
- **Цель:** Под **пользовательским** сообщением в чате планировщика добавить панель команд с двумя действиями: **«Повторить»** (переотправить тот же текст) и **«Копировать»** (скопировать текст сообщения в буфер обмена). Чисто фронтенд-задача — бэк не трогается.

## Контекст

Компоненты чата уже есть, нужно лишь добавить действия под user-сообщением:

- **Рендер сообщения:** `frontend/src/components/ChatMessage.tsx:3-12` рисует user-сообщение (role `"user"`) —气泡 справа; `tool`/`assistant` — отдельные ветки (`ChatMessage.tsx:13-26`). Сейчас под сообщением **ничего нет**; компонент принимает только `message` (`ChatMessage.tsx:3`).
- **Тип сообщения:** `PlannerMessage` (`frontend/src/hooks/usePlannerSession.ts:9-13`) — `{role, content, toolName?}`.
- **Отправка:** `usePlannerSession.send(text)` (`usePlannerSession.ts:121-133`) добавляет user-сообщение в список, выставляет `streaming=true` и шлёт текст в WS. Это и есть путь «повторить»: вызвать `send(message.content)` с тем же текстом.
- **Состояние стрима:** `streaming` (`usePlannerSession.ts:32`) — `true`, пока идёт ответ; «Повторить» стоит блокировать на время активного стрима (чтобы не слать параллельно).
- **Связь:** `Chat.tsx:46-48` рендерит `messages.map((m, i) => <ChatMessage key={i} message={m} />)` и передаёт `onSend` (`Chat.tsx:10,31-36`) + `streaming` (`Chat.tsx:12`). Нужно прокинуть `onRepeat` (= `onSend`) и флаг блокировки в `ChatMessage`.

## Затрагиваемые файлы

- `frontend/src/components/ChatMessage.tsx:3-12` — добавить пропсы `onRepeat?: (content: string) => void` и `streaming?: boolean`; под user-сообщением рендерить панель с кнопками «Повторить» и «Копировать».
- `frontend/src/components/Chat.tsx:46-48` — передать в `ChatMessage` колбэк повтора (`onRepeat={onSend}`) и `streaming`.
- (опционально) `frontend/src/components/MessageCommands.tsx` **(новый)** — вынести панель команд в отдельный компонент для переиспользования (например, под assistant-сообщениями позже).

## План действий

1. **Копирование.** В `ChatMessage` под user-сообщением кнопка «Копировать» → `navigator.clipboard.writeText(message.content)` (с fallback/визуальной обратной связью — например, кратковременная смена подписи на «Скопировано»).
2. **Повтор.** Кнопка «Повторить» → вызывает `onRepeat(message.content)` (проброшенный из `Chat` `onSend`). Блокировать (`disabled`), пока `streaming === true` или `closed`.
3. **Панель.** Расположить кнопки под пузырём user-сообщения, выровнять вправо (в стиле сообщения); мелкий текст (`text-xs`), согласовано с существующей палитрой (slate/indigo). Решить: всегда видны или по hover — рекомендация «всегда видны, но приглушены».
4. **Проброс из Chat.** В `Chat.tsx:46-48` добавить `onRepeat={onSend}` и `streaming={streaming}` в `ChatMessage`.
5. **(Опц.) Вынос компонента.** При желании — `MessageCommands.tsx` с пропсами `{content, onRepeat, streaming}`, переиспользуемый.
6. **Ручная проверка.** Под каждым user-сообщением есть «Повторить» и «Копировать»; копирование кладёт текст в буфер; «Повторить» переотправляет сообщение (появляется новый ответ планировщика) и заблокирован во время стрима.

## Критерии приёмки (Definition of Done)

- [ ] Под каждым сообщением пользователя (role `user`) в чате есть панель с командами **«Повторить»** и **«Копировать»**.
- [ ] «Копировать» помещает текст сообщения в буфер обмена; есть понятная обратная связь (например, «Скопировано»).
- [ ] «Повторить» переотправляет тот же текст (через `send`), инициируя новый ответ планировщика; заблокирован на время активного стрима/закрытого соединения.
- [ ] Под `assistant`/`tool`-сообщениями панели нет (только под user).
- [ ] `frontend`: `npm run typecheck`/`npm run lint` проходят; визуально согласовано с текущим стилем.
