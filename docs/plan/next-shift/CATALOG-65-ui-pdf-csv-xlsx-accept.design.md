# CATALOG-65 — Дизайн UI

- **Источник:** `docs/plan/next-shift/CATALOG-65-ui-pdf-csv-xlsx-accept.md`
- **Статус дизайна:** Ready

## Цель и пользовательский путь

Пользователь нажимает кнопку загрузки в `DocumentList`, системный диалог файла позволяет выбрать `.md`, `.docx`, `.pdf`, `.csv`, `.xlsx`. Сама кнопка больше не перечисляет форматы — нейтральный текст. Дальнейший путь (загрузка, список, выбор документа) не меняется.

## Дерево компонентов и файлы

- `frontend/src/components/DocumentList.tsx` — единственный затрагиваемый компонент; меняется только разметка кнопки/инпута, новых компонентов и файлов нет.

## Layout и состояния

Структура экрана и состояния **не меняются** — кнопка и файловый инпут уже существуют, новых loading/empty/error/success не появляется:

- `uploading=true` → кнопка показывает `Загрузка…` (как сейчас).
- `uploading=false` → кнопка показывает новый нейтральный текст (см. ниже).
- Ошибки (`err`, `docs.error`) рендерятся без изменений.

## Взаимодействия

- Клик по `<label>` открывает системный диалог файла с расширенным `accept`.
- После выбора файла вызывается `onFile`, инпут сбрасывается — поведение без изменений.
- Системный диалог теперь фильтрует/приоритизирует `.md, .docx, .pdf, .csv, .xlsx`.

## Конкретные изменения

Файл `frontend/src/components/DocumentList.tsx`:

- **Строка 33** — текст кнопки.
  - Было: `{uploading ? 'Загрузка…' : '+ Загрузить .md / .docx'}`
  - Стало: `{uploading ? 'Загрузка…' : '+ Загрузить документ'}`
- **Строка 37** — атрибут `accept`.
  - Было: `accept=".md,.docx"`
  - Стало: `accept=".md,.docx,.pdf,.csv,.xlsx"`

Строки 57–59 (kind-badge) **не трогать** — `d.kind` рендерится как есть в uppercase, новые значения (`PDF`, `CSV`, `XLSX`) отобразятся автоматически.

## Стиль и токены

Изменений стиля нет. Кнопка сохраняет текущие классы: `cursor-pointer rounded-md border border-dashed border-slate-700 px-3 py-2 text-center text-xs text-slate-400 hover:border-slate-500`. Текст кнопки становится короче, остатется в том же `text-xs`, перенос не появится.

## Доступность (a11y)

Изменений по a11y нет: `<label>` остаётся кликабельной областью для скрытого инпута (`className="hidden"`), фокус и клавиатура работают как раньше. Новых aria-атрибутов не требуется — состав расширяемых форматов не является семантически значимой информацией для AT, а нейтральный текст кнопки читается корректнее, чем перечисление расширений.

## Контракты данных

Контрактов данных со стороны UI нет. Типы `DocumentOut`, `UseDocumentsResult` и метод `docs.upload(file)` не меняются — новые kinds приходят с бэкенда (code-план `CATALOG-65-code`).

## Критерии визуальной приёмки

- [ ] Системный диалог открытия файла принимает `.md`, `.docx`, `.pdf`, `.csv`, `.xlsx` (атрибут `accept` содержит все пять расширений через запятую).
