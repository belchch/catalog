## Контекст

Композер в `frontend/src/components/Chat.tsx` сейчас (снизу панели, `border-t`):

1. Секция «Документы в сессии» (если есть) — `Chat.tsx:148-180`
2. **Чипы suggestions** (`visibleSuggestions`) — `Chat.tsx:181-194` — starter или ответы планировщика
3. Ряд выбранных docs + `DocumentCombobox` с placeholder `"+ документ"` — `Chat.tsx:195-229`
4. Textarea + Отправить/Стоп — `Chat.tsx:230-264`
5. «Создать скилл из сессии» — `Chat.tsx:265-275`

Проблема: suggestions визуально соседствуют с doc-контролами сверху, из-за чего «быстрые ответы» читаются как часть функциональности документов. По ТЗ порядок должен быть: сначала «+ документ» (и выбранные к отправке docs), **затем** suggestions.

Логика `visibleSuggestions` (`Chat.tsx:83-87`) и сами кнопки (`onSend(s)`) не меняются — только порядок блоков в разметке.
