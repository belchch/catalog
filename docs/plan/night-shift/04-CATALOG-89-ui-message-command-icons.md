- **Цель:** Заменить текстовые кнопки «Повторить» / «Копировать» под сообщением пользователя на компактные icon-only ghost-кнопки с inline SVG, проявляющиеся на hover без сдвига ленты, с сохранением клавиатурной доступности и логики клипборда.

## Постановка задачи (актуальное ТЗ)
_(источник: описание задачи; комментариев нет)_

Заголовок: Иконки вместо текстовых кнопок в панели команд сообщения. Тип: ui.

### Контекст
Под сообщением пользователя сейчас две текстовые кнопки — «Повторить» и «Копировать» (`frontend/src/components/MessageCommands.tsx`, рендерится из `ChatMessage.tsx`). Выглядит как ссылки в подвале, а не как панель действий: тяжело сканируется, конкурирует по весу с самим текстом сообщения. Нужно привести к виду, привычному по ChatGPT / Claude / Telegram — компактные icon-кнопки.

### Что сделать
1. Заменить текстовые подписи на icon-only кнопки:
   - «Повторить» — иконка circular arrow / refresh;
   - «Копировать» — иконка двух наложенных листов (copy).
2. Иконки — inline SVG (`currentColor`, `stroke-width` 1.5–2, размер 16px). Новую зависимость на icon-библиотеку не тянуть; вынести иконки в один небольшой модуль, чтобы переиспользовать дальше.
3. Кнопка = прозрачный ghost-квадрат ~28×28 px со скруглением, иконка по центру:
   - обычное состояние — `ink-faint`;
   - hover — цвет `ink` + мягкая подложка (`surface-muted`);
   - focus-visible — существующий ring на `brand`;
   - disabled («Повторить» во время стрима и при закрытом сокете) — приглушённый цвет, `cursor-not-allowed`, без hover-подложки.
4. Подтверждение копирования: вместо подписи «Скопировано» иконка copy на ~1.5 с меняется на галочку (можно с успешным акцентным цветом), потом возвращается. Логика клипборда и fallback для non-secure context не меняются.
5. Панель проявляется на hover сообщения (и всегда видна при фокусе с клавиатуры), но место под неё зарезервировано — при появлении/скрытии лента сообщений не должна дёргаться.
6. Доступность: у каждой кнопки `aria-label` и `title` с прежними русскими подписями («Переотправить это сообщение» / «Недоступно во время ответа» / «Копировать»), факт копирования сообщается через `aria-live`.

### Вне скоупа
Панель команд под ответами ассистента (копирование ответа, регенерация) — отдельной задачей.

Перенесены в раздел ниже.
