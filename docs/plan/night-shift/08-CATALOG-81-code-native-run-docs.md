## Контекст

`README-RUN.md` сейчас целиком про Docker Desktop + `Catalog.command` + том `catalog-data`. Документы «не в папке catalog-app». Это ломается моделью «воркспейс = папка пользователя».

`README.md` уже описывает нативный быстрый старт (`backend/.env`, venv, `uvicorn`, `pnpm run dev`) и `python scripts/golden_run.py`, но хранилище всё ещё «`workspace/` + SQLite» (`README.md:12, 30, 42–65`).

`golden_run.py` `main()` (`207–222`): tempfile → `golden.db` + `workspace/` → `Database.init_schema()` без `.catalog/index.db`. После 77 сигнатура схемы и путь БД меняются — скрипт надо либо поправить здесь, либо убедиться, что 77 уже поправил, и описать запуск из README-RUN.

`.env.example` (корень) всё ещё `APP_WORKSPACE=workspace`, `APP_DB_PATH=catalog.db`. `backend/.env.example:18–27` комментирует ADR-0012 data-root. Docker: `docker-compose.yml` named volume `catalog-data` → `/data`; `Dockerfile`, `Catalog.command`, `Build.command` — не удалять, только пометить в доке как non-local.

## План действий

1. **Структура README-RUN.** Самодостаточный документ:
   - требования: Python 3.11+, Node/pnpm, ключ провайдера;
   - шаг 1: clone/распаковка, `backend/.env` из example;
   - шаг 2: venv + `pip install -e ".[dev]"` + `uvicorn app.main:app --reload`;
   - шаг 3: `frontend` `pnpm install && pnpm run dev` (или как реально открывается UI);
   - шаг 4: в UI открыть/создать папку (пикер CATALOG-80): пустая → создать воркспейс; с файлами → подтвердить индекс;
   - где данные: выбранная папка + `.catalog/index.db`; глобальные настройки — OS data-dir, не docker volume;
   - остановка: Ctrl+C в терминалах;
   - troubleshooting без Docker (порт 8000/5173, нет ключа, 409 «откройте папку»).
2. **Docker.** Отдельный короткий раздел «Устарело для локального запуска»: named volume `catalog-data` больше не продуктовый сценарий; оставлен как задел серверного деплоя. Не удалять compose из репо в этом шаге, если TZ не просит.
3. **golden_run.** Прогнать мысленно против 77/78: `main()` должен поднимать изолированный воркспейс. Поправить пути/схему, если 77 этого не сделал. В README-RUN: команда из `backend/`, какие ключи нужны.
4. **`.env.example`.** Убрать впечатление, что документы живут в `./workspace` репозитория. `APP_DATA_DIR` для глобальной БД; воркспейс выбирается в UI.
5. Согласовать формулировки с ADR-0016 (номер из плана 76) — без отсылки «сначала прочитай ADR».
