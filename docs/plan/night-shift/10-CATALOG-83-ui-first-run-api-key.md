## Контекст

Сейчас ключи только из env. UI настроек — `ModelSelector` в хедере (`App.tsx:435–443`) переключает provider/model через `useSettings` → `GET/POST /settings` (`api.ts:411–419`). Списка «введите ключ» нет. `GET /providers` вернёт пусто/один фейк, если ключей нет (`factory.py` создаёт OpenRouter всегда, z.ai — при ключе).

После code-шага: флаг `keys_configured` и безопасный POST ключа. Этот UI:

- на старте запросить setup-статус;
- если ключей нет — полноэкранный/модальный онбординг, не основной layout;
- поля: провайдер (openrouter / zai) + ключ (password input), опционально base URL не обязателен;
- успех → показать приложение (воркспейс ещё может быть не открыт — это empty state 80).

Не показывать ключ обратно. Ошибка 401/валидации — текст на форме.

`ApiError` уже есть для status/detail.

## План действий

1. Клиент API по контракту code-шага. Ключ уходит только в POST, в GET его нет.
2. `SetupKeyScreen`: выбор провайдера, поле ключа, submit, состояние ошибки/загрузки. Копирайт: зачем ключ и где взять (openrouter.ai / z.ai) — коротко, без README.
3. `App`: пока setup неизвестен — нейтральный лоадер; `keys_configured === false` — только этот экран; иначе существующий layout (и empty workspace из 80).
4. После сохранения — `keys_configured true`, загрузить providers/models (лоадер списка — 68).
5. Повторный вход с уже сохранённым ключом экран не показывает. Смены ключа в этом шаге можно не делать (или «сменить» в том же селекторе — не обязательно).
6. `pnpm run build` / `lint` / `typecheck`. Визуал — `CATALOG-83.design.md`.

## Критерии приёмки (Definition of Done)

- [ ] Первый запуск без ключа в env/persist показывает экран ввода, основной UI недоступен.
- [ ] Успешное сохранение ключа открывает приложение; дальше можно открыть воркспейс (80).
- [ ] Ключ не отображается в UI после сохранения и не приходит в GET.
- [ ] Ошибка сохранения/невалидный ключ видна на форме, экран не сбрасывается в пустой shell.
- [ ] При уже настроенных ключах экран не показывается.
- [ ] Из `frontend/`: `pnpm run build`, `pnpm run lint`, `pnpm run typecheck` зелёные.
- [ ] Визуальная приёмка — по `CATALOG-83.design.md`.
