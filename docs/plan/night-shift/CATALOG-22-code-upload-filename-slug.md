# CATALOG-22 — Названия файлов при загрузке

- **Задача Plane:** [CATALOG-22](https://app.plane.so/belchch/projects/catalog-app/work-items/22) (id: `c30b6c83-0fb6-459f-84d8-670534c922b4`, state: In Progress)
- **Статус плана:** Analyzed
- **Тип шага:** code
- **Цель:** При загрузке документа on-disk имя должно быть человекочитаемым (слаг от оригинального имени + короткий id), а не голым UUID. `title` в БД/UI — исходное имя.

## Постановка задачи (актуальное ТЗ)
_(источник: последний комментарий от 2026-07-16)_

Составлен план выполнения (ранее): корневая причина — `ingest.py` сохранял файл всегда под UUID (`documents/{doc_id}{ext}`); title в БД и UI корректны. Фикс — транслитерация имени в слаг + суффикс id.

Содержательное требование из описания: файлы после загрузки не должны выглядеть как «кодировка» UUID вместо русскоязычного названия.
