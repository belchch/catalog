# CATALOG-109 — UI: убрать иконки обновления из заголовков секций сайдбара

- **Задача Plane:** [CATALOG-109](https://app.plane.so/belchch/projects/catalog-app/work-items/109) (id: `2c97f079-5114-468b-b68b-4213a8bf9131`, state: In Progress)
- **Статус плана:** Analyzed
- **Тип шага:** ui
- **Очередь:** 01 · независимый
- **Цель:** Убрать три кнопки «Обновить …» из заголовков секций сайдбара. Рескан в футере остаётся единственным `RefreshIcon` в сайдбаре.

## Постановка задачи (актуальное ТЗ)
_(источник: описание задачи — комментариев не было)_

Тип: UI. Нужна дизайн-спека.

В заголовках секций висят три кнопки с одним глифом `RefreshIcon`: «Обновить сессии», «Обновить документы», «Обновить скиллы». В футере тем же глифом — рескан, другое действие. Кнопки почти бесполезны: списки и так обновляются при загрузке, смене воркспейса и после операций.

Что сделать:

- Удалить три кнопки обновления из `App.tsx` (блоки `actions` секций).
- В «Сессии» оставить только «Новый чат» — `actions` сохраняется.
- У «Документы» и «Скиллы» проп `actions` не передавать.
- Убрать лишние импорты `RefreshIcon` / `SpinnerIcon` в `App.tsx`. Из `icons.tsx` не удалять.
- Hover-раскрытие `.catalog-section-header__actions` не трогать.
- Индикатор загрузки секций не добавлять.
