# CATALOG-36 — Дизайн UI

- **Источник:** `docs/plan/night-shift/CATALOG-36-ui-sidebar-collapse.md`
- **Статус дизайна:** Ready

## Цель и пользовательский путь

Боковое меню (`<aside>` в `App.tsx`) содержит три раздела: **Сессии**, **Документы**, **Скиллы**. Сейчас они всегда развёрнуты и стопкой занимают всю высоту, вытесняя друг друга за скролл.

После изменения:

1. Пользователь открывает приложение и в боковом меню сразу видит три строки-заголовка с chevron — компактный «оглавление». Контент разделов скрыт.
2. Клик по строке «Сессии» разворачивает раздел — появляются кнопки `+ Новый чат` / `Обновить` и список сессий. Повторный клик сворачивает.
3. Аналогично для «Документы» (появляется `+ Загрузить .md / .docx`, `Обновить`, список) и «Скиллы» (`Обновить`, список скиллов с действиями).
4. Состояние каждого раздела — локальное, в `App.tsx`. Все три по умолчанию **свёрнуты** (`false`). Ничего не сохраняется между перезагрузками / в backend.
5. Несколько разделов можно держать развёрнутыми одновременно — скролл `<aside>` работает как раньше.

## Дерево компонентов и файлы

### Новый

- **`frontend/src/components/CollapsibleSection.tsx`** — обёртка-коллапсер.
  - Props: `title: string`, `open: boolean`, `onToggle: (next: boolean) => void`, `actions?: ReactNode`, `children: ReactNode`.
  - Рендерит `<div>`-секцию, внутри:
    - шапка (`<button type="button">` во всю ширину строки — кликабельна целиком, включая chevron и заголовок) + опциональный `actions` справа;
    - тело с `children`, скрытое через `{open && <div>{children}</div>}` (без анимации — простой mount/unmount, чтобы не плодить зависимости; см. раздел «Стиль»).
  - Chevron — текстовый глиф `▸` (свёрнуто) / `▾` (развёрнуто). Без иконочного пакета — Tailwind v3 + Unicode, консистентно с минималистичным текущим UI.

### Изменяемые

- **`frontend/src/App.tsx`** (вокруг строк 232–251)
  - Добавить `const [openSessions, setOpenSessions] = useState(false)`, `const [openDocs, setOpenDocs] = useState(false)`, `const [openSkills, setOpenSkills] = useState(false)` (три независимых `boolean`, не `Record` — проще, читаемее, и срезу хватит).
  - Обернуть каждую из трёх панелей в `<CollapsibleSection …>`:
    - `title="Сессии"`, `actions={<>...</>}` — текущие кнопки `+ Новый чат` и `Обновить` выносятся наверх; либо (минимальный вариант) `actions` не передаём, а кнопки остаются внутри `SessionsPanel` — см. ниже remark.
    - `title="Документы"`, `title="Скиллы"` — аналогично.
  - Сохранить существующие пропсы панелей без изменений.

- **`frontend/src/components/SessionsPanel.tsx`**, **`DocumentList.tsx`**, **`SkillsPanel.tsx`**
  - Удалить корневой `<div className="flex items-center justify-between">` с `<h2>` и action-кнопками из шапки панели. Эти элементы переезжают в `actions` слот `CollapsibleSection` в `App.tsx` — это устраняет дублирование заголовков (требование плана, шаг 4) и даёт единый визуальный ряд «chevron + title + actions».
  - Корнем каждой панели становится `<div className="flex flex-col gap-2">` с контентом: ошибки / empty-сообщения / `<ul>` (для `SessionsPanel`, `DocumentList`) или список скиллов (для `SkillsPanel`).
  - **Remark (минимальная альтернатива):** если генератор решит не выносить actions (чтобы не трогать тонко логику `disabled`/`loading`-флагов внутри панелей), допустимо оставить actions внутри тела панели. В этом случае `CollapsibleSection` используется без `actions`, а из панелей убирается только `<h2>`. Любой из двух вариантов соответствует плану; вариант с `actions` предпочтителен визуально.

## Layout и состояния

Структура `<aside>` после изменений (псевдо-разметка):

```
<aside class="flex flex-col gap-4 overflow-y-auto border-r border-slate-800 p-3">
  <CollapsibleSection title="Сессии"  open={openSessions} onToggle={setOpenSessions} actions={...}>
    <SessionsPanel … />
  </CollapsibleSection>
  <CollapsibleSection title="Документы" open={openDocs}    onToggle={setOpenDocs}    actions={...}>
    <DocumentList … />
  </CollapsibleSection>
  <CollapsibleSection title="Скиллы"   open={openSkills}   onToggle={setOpenSkills}   actions={...}>
    <SkillsPanel … />
  </CollapsibleSection>
</aside>
```

Состояния `CollapsibleSection`:

- **collapsed (по умолчанию):** видна только шапка — chevron `▸` + title (+ опциональные actions). Тело не смонтировано.
- **expanded:** chevron `▾` + title + actions в шапке, под ними — тело с панелью.

Состояния панелей внутри (без изменений относительно их текущей логики — они только переезжают под коллапсер):

- **loading:** `Загрузка…` (`SessionsPanel`), `…` на кнопке `Обновить` (`DocumentList`, `SkillsPanel`).
- **empty:** `Пока нет сохранённых сессий` / пустой список документов / пустой список скиллов.
- **error:** `<p class="text-xs text-red-400">{message}</p>` — как сейчас.
- **success:** списки рендерятся как и раньше.

## Взаимодействия

- **Клик по шапке коллапсера** (везде, включая chevron и title): `onToggle(!open)`. Клик по `actions` **не** должен триггерить toggle — action-кнопки лежат вне `<button>` шапки (см. «Дерево компонентов»); клики в них останавливаются стандартным поведением (это обычные `<button>` вне toggle-кнопки).
- **Разворот** мгновенный (mount). **Сворачивание** мгновенное (unmount). Анимаций нет — простота и предсказуемость; это сознательное решение без привлечения `framer-motion` и т.п.
- **Крайние случаи:**
  - Сессия активна, пользователь свернул «Сессии» — активная сессия остаётся выбранной, индикатор вернётся при развороте. Сброса выбора нет.
  - Идёт стрим/загрузка, раздел свернули — стрим продолжается; при развороте пользователь видит обновлённое состояние (хук `useSessions`/`useDocuments`/`useSkills` живёт в `App.tsx`, не в панели).
  - Модалки (`SkillSettingsModal`) и `RunView` живут в `<main>`, на коллапсер не влияют.
- **Клавиатура:** шапка коллапсера — `<button>`, фокусируется по Tab, разворачивается `Enter`/`Space` (нативное поведение кнопки).

## Стиль и токены

Tailwind v3, в терминах существующих утилит (без новых токенов):

- Корень секции: `<div className="flex flex-col gap-2">` — консистентно с текущими панелями.
- Шапка: `<div className="flex items-center justify-between gap-2">` — повторяет паттерн текущих header-rows.
  - Toggle-кнопка (chevron + title): `<button type="button" className="flex flex-1 items-center gap-1.5 text-sm font-semibold text-slate-200 hover:text-white">`.
    - chevron: `<span className="text-xs text-slate-400">{open ? '▾' : '▸'}</span>`.
    - title: `<span>{title}</span>`.
  - `actions`: `<div className="flex items-center gap-1">` (если передан).
- Тело: `<div className="flex flex-col gap-2 pt-1">` (лёгкий отступ сверху, чтобы визуально отделить контент от шапки).
- Цветовая палитра та же, что у текущих заголовков: `text-slate-200` / `text-slate-400` / `hover:text-white`; hover-акцент мягкий, без подсветки фона строки (избегаем «кнопко-подобного» вида всей шапки — она и так `<button>`).
- Контраст: `text-slate-200` на `bg-slate-900` (фон `<aside>`) — соответствует текущему уровню контраста среза.

## Доступность (a11y)

- Шапка коллапсера — `<button type="button" aria-expanded={open} aria-controls={panelId}>`. `panelId` — стабильный id (например, `section-sessions`), генерируется из `title` или прокидывается пропсом.
- Тело: `<div id={panelId} role="region" aria-label={title}>`. `role="region"` уместен для сворачиваемого именованного блока.
- Клавиатура: фокус на toggle-кнопке по Tab; `Enter`/`Space` — нативный toggle. Внутри развёрнутого тела — обычный Tab-порядок по action-кнопкам и элементам списка.
- chevron — чисто декоративный (`aria-hidden="true"`), смысл раскрывается через `aria-expanded`.
- Контраст: заголовок `text-slate-200` на тёмном фоне проходит WCAG AA для текста ≥ 12px; chevron `text-slate-400` на том же фоне проходит AA для крупного/иконочного текста.

## Контракты данных (если нужны)

- Никаких новых API/WS/типов. Состояние `open*` — локальный `useState<boolean>` в `App.tsx`, не персистится.
- Источники данных (`useSessions`, `useDocuments`, `useSkills`) и их контракты не меняются — коллапсер только управляет видимостью, не данными.

## Критерии визуальной приёмки

- [ ] В `<aside>` отображаются три строки-заголовка: «Сессии», «Документы», «Скиллы» — каждая с chevron.
- [ ] При первичном рендере все три раздела **свёрнуты** (видны только заголовки + actions, если используется вариант со слотом `actions`).
- [ ] Chevron показывает `▸` для свёрнутого и `▾` для развёрнутого состояния.
- [ ] Клик по строке заголовка (не только по chevron) разворачивает/сворачивает раздел.
- [ ] При развороте появляется контент панели: списки, кнопки действий, empty/error-сообщения.
- [ ] Внутри панелей больше нет дублирующих `<h2>` «Сессии» / «Документы» / «Скиллы».
- [ ] Action-кнопки (`+ Новый чат`, `Обновить`, `+ Загрузить .md / .docx`) доступны — либо в шапке коллапсера (через `actions`), либо в теле панели; их `disabled`/`loading` поведение сохранено.
- [ ] Toggle-кнопка имеет `aria-expanded`, тело — `role="region"` и `aria-label`; фокус Tab'ом попадает на шапку, `Enter`/`Space` работает.
- [ ] Стиль шапки консистентен с существующими `text-sm font-semibold text-slate-200` заголовками (палитра slate-200/slate-400 не нарушена).
- [ ] Можно держать несколько разделов развёрнутыми одновременно; `<aside>` скроллится как раньше.
- [ ] Свёрнутый/развёрнутый раздел не ломает выбранный элемент (`currentSessionId`, `currentDocId`, активный скилл) — состояние сохраняется при toggle.
