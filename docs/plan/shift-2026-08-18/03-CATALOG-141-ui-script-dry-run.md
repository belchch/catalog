## Постановка задачи (актуальное ТЗ)
_(источник: описание задачи — комментариев к задаче не было)_

ADR-0023, п.7. Ручная отладка script-черновика без диалога с моделью и видимая причина, по которой сборка заблокирована. Зависит от эндпоинта dry-run и статуса прогона в payload артефакта.

Объём.

- Карточка артефакта `script` в `ArtifactsPanel` / `ArtifactSummaryCard`: кнопка прогона и статус последнего dry-run: не прогонялся / зелёный / ошибка / устарел после правки кода (хеш не совпадает).
- При ошибке — стадия (`validate` / `run` / `verify`), текст ошибки и номер строки с выделением этой строки в показе кода.
- При успехе — сворачиваемые блоки `input_preview` и `output_preview`, длина вывода, тип (`str` / `list`), длительность, исходы verify. Превью усечены и пометка об усечении видна.
- Состояния кнопки: pending во время прогона (до 5с), повторные клики не плодят параллельных запросов; отключена, когда код пуст.
- Кнопка создания скилла: если гейт блокирует сборку (нет зелёного прогона), причина видна до нажатия, а не только в виде 422 после.
- Прогоны, сделанные моделью через тул, отражаются в том же статусе без перезагрузки страницы (тем же механизмом, что уже обновляет панель артефактов).

Приёмка.

- Сверка с `docs/ui-style-guide.md`.
- Тесты компонента: статусы «не прогонялся», «зелёный», «ошибка с номером строки», «устарел после правки».
- Тест: повторные клики во время прогона не шлют второй запрос.
- `pnpm run build`, `pnpm run lint`, `pnpm run typecheck`, `pnpm run test` зелёные.

## План действий
1. Расширить `SessionArtifact` полем статуса dry-run (хеш, ok, stage, error, time, preview — как отдаст CATALOG-140). Клиент считает четыре состояния: нет статуса / ok+хеш совпал / ошибка / хеш не совпал (устарел). Несохранённый черновик в textarea ≠ прогнанный код → «устарел».
2. В секции script: кнопка «Прогнать» (`btn-secondary`), disabled при пустом коде или in-flight. Один inflight-ref: второй клик игнорируется. Pending — текст/aria-busy до ответа (таймаут ~5с на сервере).
3. Ошибка: stage, текст, номер строки; в textarea/коде выделить эту строку (класс + scroll). Успех: сворачиваемые `input_preview` / `output_preview`, len, kind, duration, verify; метка усечения видна.
4. `ArtifactSummaryCard`: рядом со «Скрипт» — тот же статус, без превью.
5. Кнопка «Создать скилл»: если гейт не зелёный — показать причину (нет прогона / устарел / ошибка) до запроса; клик можно оставить (сервер всё равно 422) или disabled — главное, причина видна заранее.
6. Прогон модели обновляет карточку через существующий `session_artifacts`, без reload.
