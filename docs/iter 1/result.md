# Iter 1 — задачи

Сводный список задач по итогам ревью. Сгруппированы по смыслу. Баги вынесены отдельно.

---

## 1. Сессия и понимание процесса

Архитектурно научить приложение понимать ход сессии и вести пользователя к результату.

- [ ] Продумать архитектуру понимания процесса сессии и промпты, ведущие пользователя к результату
- [ ] История сессий

## 2. Скилы — создание, типы, жизненный цикл

- [ ] Дать пользователю создавать **умные** или **детерминированные** (Python) скилы. Модель должна сообщать, если детерминизм невозможен, и предлагать варианты. Либо сессия изначально определяет детерминизм результата
- [ ] Скил может принимать один, два или список документов
- [ ] Жизненный цикл скила: `draft` и далее (продумать состояния)
- [ ] Перед сохранением скила предлагать пользователю настройку, в т.ч. выбор модели
- [ ] Сохранять результат как документ — дополнительный путь создания документов
- [ ] Пометка тегами: `ai` / `python`

## 3. Промпты — анализ и доработка

- [ ] Проанализировать промпты:
  - делает ли он то, что нужно?
  - можно ли сделать эффективнее?
- [ ] «Повторить промпт». Посмотреть, какие ещё фичи можно вытащить из стандартных инструментов

## 4. UI / UX

- [ ] Операция отмены запроса в чате
- [ ] Кнопки быстрых ответов в чате
- [ ] Ответы на вопросы в чате — сделать возможность выбора
- [ ] UI для выбора модели
- [ ] Лента шагов должна показывать полезную инфу максимально гранулярно: скрипт, промпт, модель и т.д. (включить модель в ленту)
- [ ] Добавить логирование в интерфейс
- [ ] Редактирование
- [ ] Выполнять в док или в окно (продумать способ вывода выполнения)

- [ ] OpenRouter доступен только по VPN — решить через другого провайдера
