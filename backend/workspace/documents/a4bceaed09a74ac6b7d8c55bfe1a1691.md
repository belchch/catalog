- **Каскад с ранним выходом (cascade):** сначала дешёвая модель, дорогую вызываем только если дешёвая не прошла порог качества. На массовых задачах экономит десятки %.
- **Ревьюер дешевле генератора, а не дороже.** Твоя схема «дорогой ревьюер» не всегда оптимальна: проверка часто проще генерации. Иногда дешёвая модель-критик + один дорогой перегенер выгоднее.
- **Разделение труда в изображениях:** дешёвая модель для черновой композиции → апскейл/доводка отдельным дешёвым специализированным инструментом, вместо одной дорогой топ-модели на весь пайплайн.
- **Кэширование и шаблонизация:** для карточек товаров огромная часть промпта повторяется. Prompt caching и переиспользование «скелета» промпта режут стоимость.
- **Batch/асинхронная обработка** там, где не нужен realtime (часто дешевле).
- **Детерминированная постобработка вместо AI:** ресайз, кроп, наложение текста, форматирование — делать кодом/шаблоном, а не гонять через модель. Это твой аргумент «не всё должно быть AI».
- **Фиксация seed/параметров** для воспроизводимости, чтобы не перегенерировать вслепую.
