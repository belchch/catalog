# Catalog — как запустить на Mac

Это программа для работы с документами. Она запускается на твоём Mac через **Docker** — это такая «коробка», в которой Catalog уже настроен и работает из коробки.

Нужно сделать два шага: один раз установить Docker, потом запускать Catalog двойным кликом.

---

## Шаг 1. Один раз: установить Docker Desktop

Нужен только в первый раз. Потом этот шаг можно пропустить.

1. Открой в браузере: https://www.docker.com/products/docker-desktop/
2. Нажми синюю кнопку **Download for Mac**.
3. На странице появится выбор между двумя версиями:
   - **Mac with Apple chip** — если у тебя процессор M1, M2, M3 или M4;
   - **Mac with Intel chip** — если процессор Intel.
   Как понять, какой у тебя: нажми в верхнем меню  → «Об этом Mac». В строке «Чип» будет написано `Apple M1`/`Apple M2`/… — это Apple chip. Если написано `Intel` — выбирай версию для Intel.
4. Скачается файл `Docker.dmg`. Открой его и перетащи иконку **Docker** в папку **Applications**.
5. Открой **Docker** из папки Applications (значок кита). Появится окно лицензии — согласись. Может попросить пароль администратора — введи пароль от твоего Mac.
6. Подожди, пока в правом верхнем углу экрана (в меню-баре) появится иконка кита. Когда она перестанет анимироваться — Docker готов.

---

## Шаг 2. Запустить Catalog

1. Распакуй архив `catalog-app.zip` — просто двойной клик по архиву. Появится папка `catalog-app`.
2. Зайди в эту папку.
3. Дважды кликни по файлу **`Catalog.command`**.

   **Если Mac скажет «не могу открыть, потому что неизвестный разработчик»:**
   - Кликни по `Catalog.command` **правой кнопкой мыши** → **«Открыть»**.
   - В появившемся окне нажми **«Открыть»** ещё раз.
   - В следующий раз Mac больше спрашивать не будет.

4. Откроется окно **Терминал** с надписью `[Catalog] Запускаю…`. Подожди ~30 секунд в первый раз (образ распаковывается). Потом автоматически откроется браузер по адресу `http://localhost:8000` — это и есть Catalog.

---

## Как остановить

Два способа:

- **Самый простой:** вернись в окно Терминала, где запущен Catalog, и нажми **Ctrl+C**.
- **Или:** запусти `Catalog.command` ещё раз — он увидит, что Catalog уже работает, и предложит остановить (нажми `s`).

---

## Где мои документы

Все документы и настройки Catalog хранятся в специальном месте Docker — «том» с именем `catalog-data`. Они:

- **Не пропадают** между запусками.
- **Не в папке `catalog-app`** — не пытайся искать их рядом со скриптом. Если удалишь папку `catalog-app`, данные всё равно останутся.

---

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| `Docker не найден` / иконки кита нет в меню-баре | Открой Docker из папки Applications. Подожди, пока иконка кита в меню-баре перестанет двигаться. |
| `Catalog уже запущен, но браузер не открывается` | Открой в браузере вручную: http://localhost:8000 |
| `port is already allocated` / занят порт 8000 | Другая программа занимает порт. Закрой другие приложения или перезагрузи Mac. |
| Иконка Catalog не загружается, крутится вечно | Проверь, что Docker запущен (кит в меню-баре). Перезапусти `Catalog.command`. |
| `no space left on device` | Docker Desktop занимается место. Открой Docker → Settings → Resources → Disk image size, увеличь до 64 ГБ или больше. |

Если ничего не помогает — скинь содержимое окна Терминала (выдели всё → Cmd+C) тому, кто тебе этот пакет прислал.
